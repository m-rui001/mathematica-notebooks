# Mathematica Notebooks · Mathematica 笔记本存档

长期使用 Wolfram Mathematica 积累的计算笔记本（`.nb`）存档，涵盖线性代数、微积分、数值计算、优化、物理建模等课程作业与个人计算实验。

> 文件为历史存档，多数文件名来自当时的随手命名，未做逐个改名；重复后缀 `(1)`、`(2)` 为编辑器产生的副本。

## 目录结构

| 目录 | 内容 |
|---|---|
| `topics/` | 文件名可辨主题的笔记本：如 `Alfred Gray-测地线`、`Bessel 函数零点求和`、`黄金分割法优化`、`3d中国地图` 等 |
| `dated/` | 以日期命名的阶段性工作（如 `10-22 行列式`、`Fit 2024-11-04`）及按文献命名的复算 |
| `scratch/` | 无名草稿与数字命名的临时计算（`1.nb`、`0713.nb`、`test.nb` 及其副本） |

## 说明

- 需要 Mathematica（建议 13.0+）打开；部分笔记本依赖本地数据文件。
- 仅按文件名模式归入目录，文件内容未改动。
